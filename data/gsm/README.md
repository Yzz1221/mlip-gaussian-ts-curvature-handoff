# GSM TS guesses

871 unoptimized TS guesses from converged GSM paths on the MLIP PES.
Files are unchanged copies of the `ts_guess.xyz` inputs in the
`Gaussian_GSM_eqV2/Gaussian_calcfc` source population used by the core-scaling
manifest. Each filename is the benchmark reaction ID; coordinates are in
angstrom and retain the source atom ordering.

`manifest.csv` records atom counts, charges, multiplicities, relative source
paths, and SHA256 checksums. The 89 benchmark reactions without converged GSM
paths have no file here. No filtering by downstream Opt+Freq or IRC success
was applied.
