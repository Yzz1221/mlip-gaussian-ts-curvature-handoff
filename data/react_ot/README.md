# React-OT TS guesses

960 unoptimized TS guesses in the React-OT exact collection.
Files are unchanged copies of the `ts_guess.xyz` inputs in the
`Gaussian_ReactOT_exact/Gaussian_calcfc` source population used by the
core-scaling manifest. Each filename is the benchmark reaction ID;
coordinates are in angstrom and retain the source atom ordering.

`manifest.csv` records atom counts, charges, multiplicities, relative source
paths, and SHA256 checksums. All 960 benchmark reaction IDs are included;
no filtering by downstream Opt+Freq or IRC success was applied. These are
React-OT predictions, not Transition1x reference TS geometries.
